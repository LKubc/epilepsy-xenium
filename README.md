# TLEseq - Single-cell spatial transcriptomics in the epileptic human hippocampus
This project contains code to reproduce figures and summary statistics for:
  **Kraus et al., “A unifying neuropathological spectrum underlies medial temporal lobe epilepsy”** (manuscript, add doi when avail).

## What this repo contains
- List overview of files here

01_MakeMegadaat: 
- This script shows how we made the main data 'MegaData_v8' also accessible on the GEO repository. We recommend working with this data file using the code provided in this repository.
  The raw per-sample GEO data can also be used, but it does not retain spatial information and we do not provide information on how to process these files for our pipeline.
