# TLEseq - Single-cell spatial transcriptomics in the epileptic human hippocampus

> ⚠️ **Work in progress**
>
> This repository is actively being developed. File names, APIs, and results may change.

## What this repo contains
- Analysis code to reproduce figures and summary statistics for:  
  **Kraus et al., “A unifying neuropathological spectrum underlies medial temporal lobe epilepsy”** (manuscript).
- Documentation on how to obtain the underlying data.
